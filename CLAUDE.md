# Claude entry point

Follow `AGENTS.md`. It owns the shared rules and task-specific reading pointers.
Read `docs/STATUS.md` only for priorities, remaining work or session continuation.

## Start a session

Read `docs/STATUS.md` and start at its "Next session, first actions" list.
`AGENTS.md` holds the shared rules and loads with this file, so you do not
need to name it.
